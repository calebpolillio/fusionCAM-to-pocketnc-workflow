# fusionCAM-to-pocketnc-workflow
**#Swissler Innovative Robotics Lab at NJIT**

This repository is a step by step workflow guide to get you from your Fusion 360 CAM file to PocketNC Kinetic Control to machining your first part! This is primarily for the transition to the machine, THIS IS NOT FOR LEARNING HOW TO CAM.

**What you will find:**

-Tips for setting up your CAM file for a Pocket NC machine

-Parameters of the pocketNC including max build volume and tool holding

-Basic Overview of the Kinetic Control software

-Transitioning your G-code into Kinetic Control

-Probing your part

-The machine in action

-Resources I found helpful in setting up my first operation

**Some prerequsite knowledge you should know:**

-Fusion 360 CAM

-Basic machining knowledge

-Understanding of CNC machining

-Understanding of feeds and speeds
